# Python News API

A Python application that fetches news articles using NewsAPI.

## Features
- Search news by keyword
- Fetches latest articles
- Displays article titles
- Displays article URLs

## Technologies
- Python
- Requests
- NewsAPI
- REST API
- JSON

## Example

### Input
Vidyanand Bapat

### Output
1. More resolute now: Pune's anti-noise campaigner Vidyanand Bapat says assault won't deter his fight...
https://timesofindia.indiatimes.com/...

2. Loud DJ row: Pune activist Vidyanand Bapat slapped during media interaction
https://timesofindia.indiatimes.com/...
